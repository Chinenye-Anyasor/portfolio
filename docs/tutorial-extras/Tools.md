# Tools

These are the tools I used to write, design, and publish my portfolio.

## Writing and editing

- **Markdown:** the format I used to write my guides.
- **VS Code:** my editor for writing and building this site.
- **Google Docs and Microsoft Word:** document drafting and review.

## Version control and publishing

- **Git and GitHub:** version control for my work.
- **Docusaurus:** the documentation framework this portfolio is built on.

## Visuals

- **Greenshot:** screenshots.
- **Lucidchart:** diagrams.
- **Canva:** the design of my homepage banner.

## AI

- **Claude:** an AI assistant I used while building this portfolio.
